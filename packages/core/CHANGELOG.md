# @arx.js/core

## 1.0.0-alpha.2

### Minor Changes

- Alpha 2: framework completo de Discord.
  
  - Gateway nativo con shards, resume, zlib-stream y heartbeat con ACK.
  - REST con buckets, rate limits, reintentos, multipart y errores tipados.
  - Comandos, contextos, middlewares, autocompletado, i18n y permisos.
  - Componentes V1/V2 completos y embeds validados.
  - Caché opt-in con LRU/TTL y estructuras lazy.
  - Bridge `@arx.js/discord.js` con la misma API y caché segura.
  - Loaders de comandos, eventos y componentes.
